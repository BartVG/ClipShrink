# Security

Please report security problems privately, through this repository's **Security** tab and **Report a vulnerability**, rather than in a public issue.

Examples that matter most here: anything that could delete or change a file without the confirmation step, or a crafted video file that makes the app misbehave.

ClipShrink makes no network connections of its own and sends no data anywhere. The installer isn't code-signed yet. Each release lists its SHA-256 checksum so you can check your download.
